# Sample media provenance

These files exist so the app can show labeled examples without shipping a board screenshot as UI.

- `dog-beach.jpg` — photographic rectangle extracted from `handoff/design/references/00-approved-direction.png` (panel 3, full-bleed area). Generated concept imagery; **not licensed for public marketing**. Replace before launch.
- `family-park.jpg` — thumbnail rectangle extracted from `handoff/design/references/02-create.png` (inspiration strip, play glyph cropped out). Same status.
- `restaurant.jpg` — downscaled copy of `handoff/fixtures/restaurant-source.jpeg` (the owner's own source photo with its watermark preserved). Private evaluation only.
- `*.mp4` next to them are **demo renders produced locally by `npm run samples:build`** (a slow push-in of the still, made with ffmpeg). They are explicitly labeled "Example" in the UI and are not AI-generated films.
